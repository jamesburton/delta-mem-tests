## Critical anti-patterns (do NOT repeat these)

| Pattern | What happened | Mitigation |
|---------|---------------|------------|
| Use the default `history_replay` mode | Predictions were bit-identical between base and delta at small sample sizes; misled us for hours | Use `official_prompt` mode (paper's protocol; matches scripts/run_qasper_multimodel_*) |
| Monolithic `model.generate` on 17.6k-token prompt | Tried to allocate 37 GB SDPA scratch on a 12 GB card | Chunked prefill via `DeltaMemChatSession._ingest_full_ids` (~1 k-token chunks) |
| Pairwise `_compute_history_len` (q0 vs q1) | Q2's prompt diverged earlier than the q0/q1 common prefix; cache poisoned and rebuilt → 37 GB OOM | Tokenise ALL qa items and intersect across every one |
| Trust `Cache.crop()` on quantised layers | TurboQuantCache and QuantizedCache layers don't preserve correctness under `crop()` | Disable cross-question KV-cache reuse for any non-bf16 backend |
| Install optimum-quanto on Windows | `gemm_cuda.cu` uses GCC `__asm__` inline assembly that MSVC can't parse | Use `hqq` backend instead (pre-built kernels) |
| Use VS 2025 with CUDA 13.x by default | `host_config.h` rejects VS 2025 (allows only 2019–2022) | `env/vsenv.ps1` sets `NVCC_PREPEND_FLAGS=-allow-unsupported-compiler` |
