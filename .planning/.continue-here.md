## Hard-earned lessons (do not forget)

- **Worktree isolation isn't always isolating writes**: agents' Edit/Write tools target absolute paths and can leak into the main worktree. Always check `git branch --show-current` and `pwd` before committing in mixed-state sessions.
- **Bash CWD drifts** if you `cd` into worktrees during inspection. Re-orient before each git commit/push.
- **PowerShell ExecutionPolicy** blocks `-File` invocations on Strix; use `-ExecutionPolicy Bypass`.
- **Activate.ps1** also hits ExecutionPolicy; call `.venv\Scripts\python.exe` directly.
- **scp -r** nests into existing remote dirs; use the `./dir/.` trailing-merge idiom OR install rsync.
- **Triton-Windows AMD backend** has a bf16-affine-scan codegen bug on gfx1151; force `DELTA_MEM_SCAN_IMPL=torch`.
- **locomo_eval.py reuses existing output JSONs**; rename to `*.STALE.json` before re-running.
- **`ssh strix` from msys2/Git-Bash** fails with libcrypto error; helper now picks the native Windows OpenSSH automatically.
- **rocm-smi is not bundled** with ROCm-on-Windows 7.1; use `python -c "import torch; print(torch.cuda.is_available())"` as the GPU-ready gate instead.
